## 一、应用名称

**ArkDesk — 远程桌面助手**

（备选短名：ArkDesk 远程桌面）

## 二、一句话简介（≤ 80 字，用于列表页）

基于开源 RustDesk 的 HarmonyOS 远程桌面客户端，可远程查看与控制您的电脑，支持文件传输与自建服务器，数据不经第三方。

## 三、应用介绍（≤ 1000 字，用于详情页）

**ArkDesk 是一款基于知名开源项目 RustDesk（AGPL-3.0）构建的远程桌面客户端，为 HarmonyOS 设备提供安全、流畅的远程控制与文件传输能力。**

**▍主要功能**

- **远程控制**：连接您的 Windows、macOS、Linux 或其他设备，实时查看屏幕并使用触屏手势、软键盘进行键鼠操作；
- **文件传输**：在本机与远程设备之间双向传输文件与图片，支持断点续传式的目录浏览；
- **多显示器切换**：远程设备有多个显示器时可自由切换查看；
- **画质调节**：提供画质预设，可在流畅与清晰之间按网络状况权衡；
- **自建服务器**：完整支持配置您自己的 ID / 中继（rendezvous/relay）服务器，连接链路完全由您掌控；
- **可选 EasyTier 预组网**：安装 EasyTier 应用后，可在连接前自动建立虚拟组网，简化内网设备的直连流程；
- **跨设备接力**：支持通过 arkdesk:// 链接从其他设备快速发起连接。

**▍安全与隐私**

- 所有数据仅在您的设备与您所配置的服务器之间传输，开发者不收集、不存储您的任何屏幕画面、账号或连接记录；
- 应用首次使用前需您在系统内同意隐私协议；未同意前，运动传感器等敏感能力保持关闭；
- 剪贴板读取仅在您主动发起连接时生效，并遵循系统权限管理。

**▍开源声明**

ArkDesk 基于 RustDesk 项目（https://github.com/rustdesk/rustdesk，AGPL-3.0 许可证）修改而成，本应用的完整源码依据许可证要求公开于：

https://github.com/WLX2007/arkdesk

ArkDesk 为社区独立开发的非官方客户端，与 RustDesk 官方（Purslane Ltd）无隶属或代言关系。

**▍适用设备**

手机 / 平板 / 二合一（PC）设备，支持横屏与多窗口形态。

## 四、常见问题（FAQ，可用于审核备注或详情页附录）

1. **ArkDesk 和 RustDesk 是什么关系？**
   ArkDesk 是 RustDesk 的 HarmonyOS 社区移植版本，遵循 AGPL-3.0 开源许可，源码公开，非官方出品。

2. **连接需要账号吗？**
   不需要。直接输入远程设备的 ID 与密码即可连接，也可配置自建服务器。

3. **数据会被收集吗？**
   不会。本应用不内置任何统计或埋点 SDK，不收集设备信息、屏幕画面或连接记录。

4. **为什么需要"读取剪贴板"权限？**
   仅用于在您连接远程设备后同步剪贴板内容，可在系统中随时关闭。

5. **EasyTier 是必需的吗？**
   不是。EasyTier 预组网为可选功能，未安装时所有功能均可正常使用。

## 五、审核备注建议（提交 AGC 时填写）

- 本应用为开源项目 RustDesk 的 AGPL-3.0 修改版，源码：https://github.com/WLX2007/arkdesk；
- 应用仅作为远程桌面**主控端**（控制远端设备），不实现本机被控/监听能力；
- `ohos.permission.INTERNET`：与用户指定的远程设备及服务器建立连接；
- `ohos.permission.READ_PASTEBOARD`：连接建立后同步剪贴板，页面内已提供用途说明；
- `ohos.permission.KEEP_BACKGROUND_RUNNING`：保持长连接与数据传输不断开；
- `ohos.permission.INTERCEPT_INPUT_EVENT`：远程会话中采集本地触控/按键并转发给远端（附权限说明视频）；
- `ohos.permission.READ_MEDIA`/文件相关操作均通过系统选择器发起，未经用户选择不读取任何文件。
